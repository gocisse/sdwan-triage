What is a DDoS Attack?

A Distributed Denial of Service (DDoS) attack floods a target with traffic to overwhelm it. Signs include: unusually high packet rates from single sources, SYN floods (many connection attempts without completion), and UDP floods targeting specific ports.

Attack Type Source IP Target IP Packets Severity Impact
SYN Flood 10.11.2.201 44.205.176.169 2,847 Critical Service disruption likely
UDP Flood 10.11.1.217 10.77.1.71 1,523 High Bandwidth exhaustion
SYN Flood 10.11.2.17 10.199.1.100 1,245 High SMB service targeted
ICMP Flood 10.11.3.252 10.199.2.100 892 Medium Network latency increase
Junior Engineer Actions
  • Step 1: Check if multiple services are affected. If YES → ESCALATE IMMEDIATELY
  • Step 2: Verify source IPs are internal (10.x.x.x). Internal sources suggest compromised hosts.
  • Step 3: Do NOT block IPs without senior approval - you might block legitimate traffic.
  • Step 4: Document attack patterns and escalate to Security team with this report.

What is Port Scanning?

Port scanning is reconnaissance activity where an attacker probes a system to find open ports and services. This is often the first step before an attack. Types include: Vertical (many ports on one host), Horizontal (one port across many hosts), and Block scans (many ports across many hosts).

Understanding DNS Anomalies

DNS anomalies can indicate: DNS Hijacking (queries redirected to malicious servers), DNS Tunneling (data exfiltration via DNS), or Misconfiguration (internal domains resolving to private IPs). Private IPs (10.x, 192.168.x) returned for public domains is suspicious.

Understanding TCP Handshakes

A TCP connection requires a 3-way handshake: SYN → SYN-ACK → ACK. Failed handshakes mean the connection couldn't be established. Common causes: firewall blocking, service not running, network path issues, or resource exhaustion.
