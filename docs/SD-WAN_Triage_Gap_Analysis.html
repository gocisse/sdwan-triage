Critical Gaps (Blocks Accurate Diagnosis)

C1: TCP Stream Reassembly ❌

Impact: Cannot view complete HTTP requests/responses, file transfers, or application payloads that span multiple packets.

Current State: Only per-packet payload length shown.

Required: Reassemble TCP streams, handle out-of-order packets, display full application data.

C2: TCP Time-Sequence Graph ❌

Impact: Cannot visualize retransmissions, window scaling, or congestion patterns over time.

Current State: Retransmission counts exist but no visual timeline.

Required: Stevens-style or tcptrace-style graph showing seq/ack over time with annotations.

C3: Follow Stream ❌

Impact: Cannot trace a single conversation across all packets.

Current State: StreamConversation component exists but doesn't filter/highlight related packets.

Required: Click any packet → see all packets in that TCP/UDP stream highlighted.

C4: TLS Decryption ✅ RESOLVED

Status: NSS Key Log parsing + AES-GCM decryption now implemented. Supports TLS 1.2 and TLS 1.3.

Usability Gaps (Annoying to Use)

U1: No Display Filter Autocomplete

Users must memorize Wireshark filter syntax. Required: Dropdown with ip.src, tcp.port, etc. as user types.

U2: No Packet Colorization

All packets look the same; hard to spot patterns visually. Required: Color rules (red for RST, yellow for retransmissions).

U3: No Keyboard Navigation

Mouse-only interaction slows power users. Required: Arrow keys to navigate, Enter to expand, Ctrl+F for search.

Advanced Gaps (Nice-to-Have)

A1: GeoIP Visualization

Map overlay showing source/destination countries for geographic traffic distribution.

A2: Protocol Hierarchy Statistics

Tree view showing % of TCP vs UDP vs ICMP, HTTP vs HTTPS, etc.

A3: IO Graphs

Packets/sec or bytes/sec graph with zoom for throughput visualization over time.

Missing Learning Aids

  • Glossary/Tooltip Links — Terms like "DSCP", "TTL", "MSS" should link to definitions
  • Sample PCAP Library — Curated examples: "TCP handshake", "DNS failure", "TLS negotiation"
  • Practice Scenarios — "Find the dropped packet in this capture" with hints and solutions
  • RFC/Documentation Links — "Learn more about TCP flags → RFC 793 Section 3.1"
  • Progress Tracking — Gamification: "You've analyzed 15 captures and identified 3 policy drops"

Verdict: Educational Layer is Best-in-Class

The tool already teaches better than any competitor. Adding a glossary + sample PCAPs would make it a genuine training platform and elevate it to world-class status.
